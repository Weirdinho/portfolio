# Umar Gusau — Personal Portfolio

A premium single-page React/Vite portfolio built from the supplied portfolio brief.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Main customization file

Edit `src/data/siteData.js` to change your name, role, email, GitHub, LinkedIn, skills, and project data.

Replace `GITHUB_URL_HERE`, `LINKEDIN_URL_HERE`, `LIVE_URL_HERE`, and `YOUR_EMAIL_HERE` with real values before publishing.

Project visuals are intentionally CSS-based placeholders so the portfolio remains runnable without inventing screenshots. Replace them with real screenshots in `ProjectVisual` when available.

## Deploy to Render

Create a Static Site in Render, connect the repository, and use:

- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

## Notes

- React + JSX + JavaScript
- Normal CSS
- No Tailwind
- No TypeScript
- Responsive mobile/tablet/desktop layouts
- Reduced-motion support
- Semantic sections and accessible navigation
